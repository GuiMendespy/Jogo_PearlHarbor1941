# ⚓ Pearl Harbor 1941 — Jogo de Batalha Naval 🚢🔥

Este repositório apresenta **Pearl Harbor 1941**, um **jogo 2D de Batalha Naval** desenvolvido em **C++**, utilizando **Programação Orientada a Objetos (POO)** e **gráficos em ASCII Art**. O jogo combina estratégia, turnos e posicionamento tático para recriar combates navais de forma interativa no terminal.

📌 **Sobre o Jogo**

🎮 **Batalha Naval em ASCII Art**
O jogador deve **posicionar sua frota**, planejar ataques estratégicos e derrotar o oponente em combates navais por turnos.

🚢 **Mecânicas Principais**

* Posicionamento **aleatório** de navios
* Sistema de combate por **turnos**
* Ataques estratégicos ⚔️
* Verificação de acertos e destruição de navios

🕹️ **Modos de Controle**

* **WASD + tecla de ataque**
* **Setas do teclado + Enter para atacar**

🧠 **Conceitos Aplicados**

* Programação Orientada a Objetos (POO)
* Controle de estados do jogo
* Lógica de movimentação e colisão
* Estruturação modular do código

🎯 **Objetivos**

* Desenvolver um jogo completo em C++
* Aplicar conceitos de POO na prática
* Criar uma experiência interativa em terminal
* Trabalhar lógica e estratégia de jogos

🛠️ **Tecnologias**

* C++
* Programação Orientada a Objetos
* ASCII Art
* CLion

📚 **Observação**
📘 Projeto desenvolvido com **fins acadêmicos**, voltado ao aprendizado prático de **desenvolvimento de jogos, POO e lógica de programação**.
